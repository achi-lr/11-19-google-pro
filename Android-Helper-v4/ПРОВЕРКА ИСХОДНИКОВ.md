Android Helper v4 includes the source code alongside the executable.

- `src/AndroidHelper.cs`: native C# WinForms interface and process launch. Google sign-in uses a fixed worker action, with no account input fields.
- `src/UiText.cs`: Russian and English interface strings.
- `src/Preferences.cs`: saves only `language` and `theme` to local settings.json.
- `src/desktop_worker.py`: UTF-8 process bridge. `open-login` starts Android's Add Account screen with the Google account type. It reads no credentials and performs no text input or button clicks.
- `src/ru_logs.py`, `src/en_logs.py`: translate log presentation; keep technical identifiers and paths.
- `src/android_launch.py`: resolves the launcher activity and waits for the application process.
- `src/core.py`: original supplied engine. Its subscription and confirmation functions remain present. The wrapper replaces automatic subscription-page navigation with a separate UI button.
- `src/billing.js`, `src/billing-module.apk`: resources from the supplied project. The Java activity lookup fix from v3 is retained.
- `build.ps1`: rebuilds the C# application and Python/PyInstaller worker. Python, PyInstaller and Frida are required for rebuilding, not for running the package.
- `runtime/`: bundled ADB, Python runtime and Frida. ADB notices are in runtime/NOTICE.txt.

The package contains third-party binaries, including a supplied APK. They have not undergone a complete security audit. Readable sources and SHA-256 hashes support inspection and integrity checks; they do not establish that every binary is harmless. No signing certificate is included.

Version 4 removes the account autofill helper and its UI from the package. Original engine functions remain for inspection; the UI does not invoke account credential entry. The new sign-in action only requests Android navigation. Existing local logs from older versions are not rewritten.

Validation: C# compilation; light/dark interface rendering; settings persistence and malformed-settings fallback; RU/EN log translation; mocked Google sign-in navigation without credential entry; packaged worker resource/UTF-8 check. No new subscription purchase is part of these checks.
